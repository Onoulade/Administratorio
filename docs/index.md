# Administratorio Documentation

**The factory must grow. Subject to approval.**

## Overview

An overhaul mod for Factorio 2.0 that replaces military conflict with corporate bureaucracy. No guns. No turrets. No military science. Every machine you build, every inserter you place, and every furnace you fire up requires the proper paperwork — and the biters you used to shoot now have HR representation and a grievance process.

- **Requires:** Factorio 2.0

- **Incompatible with:** Space Age, Quality
